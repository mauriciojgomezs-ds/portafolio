# Historial de evolución del MVP

Resumen de las etapas documentadas anteriormente, expresado con nombres genéricos. La guía vigente está en el [README](../README.md).

| Etapa | Evolución |
| --- | --- |
| Orígenes y etiquetas | Registro de sitios, tags y consultas locales o con ingesta web. |
| Cobertura documental | Checklist de introducción, permisos, configuración, validación y referencias técnicas. |
| Descubrimiento multi-origen | Búsqueda pública, conector de documentación y semillas complementarias para temas conocidos. |
| Ranking por intención | Priorización por conceptos, acciones y patrones de URL. |
| Contexto por ejecución | Prioridad a las URLs recién ingeridas, con fallback a la base local. |
| Documentación del portafolio | Guías de uso, arquitectura, limitaciones y protocolo de evaluación de una futura integración con IA. |
| Componentes genéricos | Nombres de seguimiento web, mensajería, reglas de acción y enrutamiento; eliminación de una fuente implícita y de semillas propietarias. |

La consulta web requiere ahora un tag registrado explícitamente. Los filtros, las versiones históricas y el feedback compartido conservan las limitaciones descritas en la [guía de diagnóstico](limitaciones.md).
