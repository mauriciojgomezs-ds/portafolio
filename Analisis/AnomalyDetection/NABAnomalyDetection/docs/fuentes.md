# Fuentes de NABAnomalyDetection

Fuente pública de referencia: [sitio de descarga](https://github.com/numenta/NAB). La correspondencia y condiciones de uso de la descarga deben revisarse con la documentación de origen.

Las entradas son locales al proyecto:

- `data/raw/NAB.zip` (48,012,310 bytes).

Las huellas SHA-256 están en [fuentes.json](fuentes.json). Puedes recuperar las fuentes con `python scripts/download_sources.py`. Los datasets no se versionan. Compartir el proyecto exige suministrar sus datos por un medio permitido o seguir sus instrucciones de obtención; no requiere otra carpeta del portafolio.

Las copias originales del portafolio se conservaron como archivo; ninguna función de este proyecto las utiliza. Las métricas y supuestos se describen en [metodologia.md](metodologia.md).
