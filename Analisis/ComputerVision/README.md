# Visión computacional

[FashionMNISTClassification](FashionMNISTClassification/README.md): clasificación de prendas, comparación lineal/MLP, evaluación por clase y análisis visual de errores. Incluye notebooks por etapa e informe integral automático.

[DigitsRecognition](DigitsRecognition/README.md) incorpora reconocimiento de dígitos 8×8 con intensidad, gradientes y SVM. Compara con centroides, muestra errores y mide sensibilidad a un desplazamiento artificial de un píxel. Es independiente de Fashion-MNIST.
