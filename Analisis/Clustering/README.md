# Segmentación y clustering

| Proyecto | Población | Características |
| --- | --- | --- |
| [CustomerSegmentation](CustomerSegmentation/README.md) | Clientes con compras positivas identificadas | Recencia, frecuencia e importe |
| [SpotifySegmentation](SpotifySegmentation/README.md) | Muestra reproducible de canciones | Características musicales |

Se comparan reglas simples y KMeans, con silhouette, estabilidad entre semillas y perfiles en unidades originales. Los clusters son descriptivos y requieren interpretación; no se asignan nombres de negocio sin evidencia. Consulta la [guía compartida](../../docs/proyectos_tematicos.md).
