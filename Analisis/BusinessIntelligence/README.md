# Análisis de indicadores de negocio

[RetailKPIAnalysis](RetailKPIAnalysis/README.md) analiza facturación positiva, ajustes negativos y facturación neta de Online Retail en GBP. Incluye comparación mensual, controles de reconciliación y un dashboard HTML generado como resultado del análisis.

Su recorrido se realiza mediante notebooks y produce un [informe integral](RetailKPIAnalysis/reports/informe_final/informe_final.md). Sigue la misma estructura independiente que los otros proyectos de análisis. Consulta la [guía temática](../../docs/proyectos_tematicos.md).
