# Fuente y recuperación

[Stanford SNAP email-Eu-core](https://snap.stanford.edu/data/email-Eu-core.html). Red anonimizada con 1.005 nodos y etiquetas de 42 departamentos. Arista dirigida = al menos un correo; no contiene texto, volumen ni comunicaciones externas. Se descargan ambos GZ mediante `scripts/download_sources.py`. La fuente aporta instrucciones de citación; no se presupone una licencia distinta a sus condiciones publicadas.

00 recupera entradas si faltan; no reemplaza fuentes locales existentes. Preparación guarda SHA-256. Conserva `data/raw` al copiar el proyecto.
