# Fuentes de RetailSalesForecasting

Fuente pública de referencia: [sitio de descarga](https://archive.ics.uci.edu/dataset/352/online+retail). La correspondencia y condiciones de uso de la descarga deben revisarse con la documentación de origen.

Las entradas son locales al proyecto:

- `data/raw/OnlineRetailUCI.zip` (23,715,478 bytes).

Las huellas SHA-256 están en [fuentes.json](fuentes.json). Para una copia nueva del repositorio, coloca los archivos de origen con estos nombres dentro de `data/raw/` antes de ejecutar 01. Los datasets no se versionan. Compartir el proyecto exige suministrar sus datos por un medio permitido o seguir sus instrucciones de obtención; no requiere otra carpeta del portafolio.

Las copias originales del portafolio se conservaron como archivo; ninguna función de este proyecto las utiliza. Las métricas y supuestos se describen en [metodologia.md](metodologia.md).
